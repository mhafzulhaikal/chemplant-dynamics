Process Control Theory & PID Tuning

Mathematical Foundations of Feedback Control Loops

1. Continuous PID Controller Algorithm

The standard parallel continuous-time PID algorithm in ideal gain form is defined as:

$$u(t) = K_p e(t) + K_i \int_{0}^{t} e(\tau) d\tau + K_d \frac{de(t)}{dt}$$

Where $u(t)$ is the controller output ($0-100\%$) and $e(t) = SP - PV(t)$ represents the instantaneous control error.

2. Discrete Velocity Form (Anti-Windup)

For discrete numerical simulation and microcontroller implementation, the algorithm is expressed in velocity form to prevent integral windup:

$$\Delta u_k = K_p \left( e_k - e_{k-1} \right) + K_p \frac{\Delta t}{\tau_i} e_k + K_p \frac{\tau_d}{\Delta t} \left( PV_k - 2 PV_{k-1} + PV_{k-2} \right)$$
$$u_k = u_{k-1} + \Delta u_k$$
